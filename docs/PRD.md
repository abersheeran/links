# 多租户短链接服务 PRD

## 1. 产品定义

Links 是一个多租户短链接服务，同时提供机器 API 与同源 Web 控制台。每个租户拥有独立域名、独立 API Key、用户、会话和互相隔离的短链空间；访客通过租户域名访问短码时，服务返回 302 跳转，并将匿名点击事件写入分析系统。

产品目标是提供一套边界清晰、可直接部署在 Cloudflare 上的短链基础设施，并让租户团队在没有共享万能钥匙的情况下完成链接运营、访问分析和成员权限管理。

## 2. 目标用户

| 用户         | 需求                                   |
| ------------ | -------------------------------------- |
| 平台运营者   | 创建和停用租户，为租户分配独立域名     |
| 租户所有者   | 管理成员、API Key、短链和访问分析      |
| 租户编辑者   | 创建和维护短链，查看分析并使用 AI 建议 |
| 租户只读成员 | 查看短链和访问分析，不产生写入         |
| 租户开发者   | 通过 API Key 进行服务端集成与自动化    |
| 终端访客     | 通过稳定、低延迟的短链访问目标页面     |

## 3. 核心概念

- **租户**：数据隔离边界。租户拥有唯一 slug 和至少一个访问域名。
- **域名**：短链的公开入口。一个域名全局只能归属一个租户。
- **API Key**：租户 API 的 Bearer 凭证。明文只在创建时返回一次。
- **用户**：属于某一租户、使用邮箱和密码登录控制台的身份。
- **会话**：浏览器登录后建立的 7 天服务端会话，使用 HttpOnly Cookie。
- **角色**：`owner`、`editor`、`viewer`，决定 API 权限和控制台可见操作。
- **短链**：租户内唯一的短码到 HTTP(S) 目标地址的映射。
- **点击事件**：一次短码访问的结果，包括成功跳转、禁用、过期或不存在。

## 4. 首版范围

### 4.1 租户开通

- 平台运营者使用平台级 Bearer Token 创建租户。
- 平台运营者可以列出最近创建的租户，并为指定租户补发 API Key。
- 创建租户时必须同时指定名称、slug、主域名和首个 API Key 名称。
- 创建租户时可以直接附带首个所有者账号；也可以之后通过平台接口补建。
- 平台运营者可以创建任意角色的租户用户，并重置用户密码以完成账户恢复。
- 创建成功后在响应中返回一次 API Key 明文。
- 若首次开通响应丢失，平台运营者可以补发恢复用的 API Key。
- 平台级 Token 未配置时，租户开通接口不可用。

### 4.2 登录、会话与权限

- 控制台与 API 由同一 Worker 同源提供，不跨域传递会话。
- 用户使用邮箱和密码登录；密码使用 PBKDF2-SHA256 加盐哈希保存。
- 登录按访问域名确定租户；在未绑定租户的域名上登录时明确提示域名未绑定，而不是提示邮箱或密码错误。
- 登录失败 5 次后锁定 15 分钟；成功登录会重置失败计数。
- 会话有效期 7 天，使用 `HttpOnly`、`SameSite=Lax` Cookie；HTTPS 下带 `Secure`。
- 浏览器会话的所有写操作必须携带会话专属 CSRF Token。
- 修改密码会撤销该用户除当前会话外的其他会话；所有者重置密码或停用成员会撤销目标用户的全部会话。
- 角色权限只在 API 层做最终判断，前端隐藏导航和按钮只是用户体验，不是安全边界。
- 所有者可添加编辑者或只读成员、调整角色、停用/恢复成员和重置成员密码。
- 所有者账号不能通过租户控制台降级或停用，只能由平台运营者处理。

### 4.3 控制台

- 提供登录页、总览、短链管理、访问分析、团队、API Keys 和账户设置。
- 导航和页面入口根据权限显示；直接访问无权限路由时显示 403 状态页。
- 总览展示最近 7 天点击、链接总量、主要设备、主要来源国、点击趋势和最近链接。
- 短链页支持搜索、状态筛选、游标分页、创建、编辑、删除、复制与 AI 元数据补全。
- 团队页只对所有者开放；API Keys 页只对所有者开放。
- 账户设置允许当前用户修改密码并查看自己的权限集合。

### 4.4 API Key 管理

- 租户可以创建额外 API Key，用于轮换或不同系统接入。
- API Key 列表只显示前缀、名称和使用时间，不显示明文或哈希。
- 租户可以撤销 API Key。
- 禁止撤销租户最后一个有效 API Key，避免永久失去 API 访问能力。

### 4.5 短链管理

- 支持自动生成短码或指定自定义短码。
- 短码在租户内唯一，不同租户可以复用同一短码。
- 支持标题、描述、标签、启用/禁用状态和过期时间。
- 只允许目标地址为绝对 HTTP(S) URL，不接受带用户名或密码的 URL。
- 支持按状态、关键词和游标分页列出短链。
- 支持读取、更新和删除短链。
- 短码创建后不可修改，避免已投放链接失效。

### 4.6 公开跳转

- 根据请求 Host 找到租户，再按短码查找链接。
- 成功时返回 `302`，并将来源查询参数追加到目标 URL。
- 禁用链接和过期链接返回 `410`。
- 未知域名或未知短码返回 `404`。
- 所有跳转响应禁止缓存，并标记 `noindex`。

### 4.7 点击分析

- 每次访问短码都写入一次 Analytics Engine 事件。
- 成功跳转计入点击量；禁用、过期和不存在事件保留用于诊断，但不计入点击总量。
- 分析接口返回指定时间范围的总点击、时间序列、热门短链、国家、来源域名、设备、浏览器和 UTM 活动。
- 控制台用趋势图、设备环图、横向条形图和链接排名展示分析结果。
- 查询范围最长 90 天，与 Analytics Engine 数据保留周期一致。
- 分析查询需要单独的只读 API Token；未配置时返回明确的不可用错误。

### 4.8 AI 辅助

- 租户可提交目标 URL，由 Workers AI 生成标题、描述、标签和短码建议。
- AI 只接收 URL，不抓取目标页面内容，不声称知道页面事实。
- AI 不可用、输出非法或全部建议短码无效时，返回基于 URL 的确定性降级建议。
- AI 建议不直接创建短链。

## 5. 明确不做

- 不做计费、套餐、配额和在线支付。
- 不做邮件找回密码、邮件邀请或自助注册；初始密码由所有者或平台运营者设置。
- 不做 SSO、多因素认证或成员级 API Key 作用域。
- 不做租户自助添加域名或验证域名所有权。
- 不做 QR Code、批量导入、A/B 测试、密码保护链接或地理跳转。
- 不做点击次数上限和并发计数。
- 不保证跨地域立即生效的禁用；KV 缓存最长有 60 秒传播窗口。
- 不保存访客 IP，不保存完整 Referer，只保存 Referer 域名。

## 6. 一致性与可用性

- D1 是租户、域名、用户、会话、API Key 和短链的事实来源。
- KV 只做正向缓存，不缓存“未找到”；缓存故障时回退 D1。
- 租户域名缓存和短链缓存 TTL 均为 60 秒。
- 更新或删除短链会主动写入或删除当前边缘的缓存，但其他地域仍可能短暂读到旧值。
- Analytics Engine SQL API 不可用时，分析接口返回 `502`；跳转不受影响。
- Workers AI 不可用时，AI 建议接口使用降级结果，仍返回 `200`。
- Analytics Engine 保留点击数据 90 天；新出现的事件维度对旧事件显示为未知值。

## 7. 安全与隐私

- API Key 使用 24 字节随机秘密，数据库只保存 SHA-256 哈希和可检索前缀。
- 平台 Token 和 API Key 校验使用常量时间比较。
- 平台开通与补发接口应额外由 Cloudflare Access 或 WAF 速率限制保护；登录接口也应配置 WAF 速率限制。
- 用户密码使用 PBKDF2-SHA256（100,000 次迭代、随机盐）保存，从不存储明文。
- 会话 Token 只保存 SHA-256 哈希；CSRF Token 与会话绑定并通过响应体交给同源前端。
- 会话写操作校验 CSRF；登录接口拒绝跨源 Origin。
- 所有租户数据查询都带有 `tenant_id` 条件。
- 短码生成使用 Web Crypto，不使用 `Math.random()`。
- 公开跳转不记录 IP；点击事件保留国家、来源域名、设备、浏览器、UTM 活动、User-Agent、短码、租户和结果。
- 目标 URL 可能有敏感查询参数，但不会写入分析事件。

## 8. 成功标准

- 新租户可以在 5 分钟内完成开通并创建第一条短链。
- 所有者能在控制台创建编辑者和只读成员，并验证不同角色的导航与 API 权限差异。
- 登录、退出、密码修改、成员停用和会话撤销有可测试的状态变化。
- 同一短码在不同租户下互不影响，跨租户读取返回 `404`。
- 成功跳转在 KV 命中时不访问 D1。
- 禁用、过期和不存在三类状态有稳定且可测试的 HTTP 语义。
- Analytics Engine 查询计入采样权重，不把采样后行数直接当点击量。
- 分析页能展示点击趋势、设备、国家、来源、浏览器和 UTM 活动图表。
